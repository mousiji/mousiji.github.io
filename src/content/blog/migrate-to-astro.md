## 缘起

这个博客最早是用 **Gridea** 搭建的，一个很不错的静态博客写作客户端。但好几年没更新了，趁着最近有时间，决定把它迁移到更现代的框架上。

## 为什么选 Astro？

对比了几个方案：

| 框架 | 优势 | 劣势 |
|------|------|------|
| **Astro** ✅ | 现代、快速、Markdown 原生支持、岛屿架构 | 相对较新 |
| Hugo | 极快、成熟 | Go 模板语法不熟悉 |
| Hexo | 中文生态好、插件多 | 比较古早 |
| VitePress | 文档风格、简洁 | 偏向文档站点 |

最后选了 **Astro**，因为：
- 原生支持 Markdown 和 MDX，写文章体验好
- 卡片式设计 + 深色模式，视觉上更现代
- 部署到 GitHub Pages 依然是免费的

## 过程

1. 搭建 Astro 项目骨架
2. 设计卡片式布局和深色模式
3. 迁移旧文章内容
4. 添加 Giscus 评论系统
5. 配置友链页面
6. 配置 GitHub Actions 自动部署
